# News Intelligence Agent

## Responsibilities
- Receive search results
- Filter irrelevant articles
- Remove duplicates
- Clean content
- Normalize metadata
- Forward structured news to Risk Agent

## Workflow

Search API
      ↓
News Agent
      ↓
Structured News
      ↓
Risk Agent
      ↓
Risk Assessment

## Agent Lifecycle

Receive
→ Validate
→ Filter
→ Clean
→ Normalize
→ Output
